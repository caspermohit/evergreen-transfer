EVERGREEN TRANSFER WEBSITE

Next.js app for the Evergreen Transfer redesign. The original static files
(index.html, styles.css, and app.js) are still in this folder.

RUN THE NEXT.JS SITE
  npm install
  npm run dev
Then visit http://localhost:3000

PRODUCTION
  npm run build
  npm start

The estimate form prepares an email draft. It does not submit a booking.
Images are in public/assets. Fonts are loaded with next/font.
